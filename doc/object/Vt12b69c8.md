# object::Vt12b69c8

PLACEHOLDER name. 0x318-byte resource-entry object (Vt12bad28 is its
only known derived class). Derives the 0x38-byte Vt12be2d0-family base:
C1 FUN_71006b5e2c (92 B) first calls the base C1 0x732a90 (installs base
row 0x12be350 from cell 0x130e980, zeroes +0x08/+0x10), then overwrites
+0x00 with its own vptr.

- Identity: vptr = 0x12b69c8; [vptr-0x10]/[vptr-8] = 0 (no offset-to-top,
  no typeinfo). GOT cell 0x130e070 holds 0x12b69b8 = vt-0x10.
- Size proof: derived-class factory 0x6f786c requests 0x318 bytes
  (0x6f78f0, w3 = 0x318) from the allocation helper 0x6ad048 and
  constructs the Vt12b69c8 base with FUN_71006b5e2c at 0x6f7914 before
  installing the derived vptr.
- Behavior: slot2 0x6b5f80 (FUN_71006b5f80) re-reads the entry table:
  entry = [mSource08+0x108] + mIndex14*0x68; copies [entry+0x5e] to
  +0x16, [entry+0x50] to +0x20, [[mSource08+0x110] + ([entry+0x5e]<<7)]
  + 0x88 to +0x28, [entry+0xd] flag into bit1 of +0x32, and
  [mSource08+0x1618] u16 into +0x10; then writes the shared default
  pointer 0x1357f58 into all 88 table slots at +0x38..+0x2f7. Reads like

- D1 0x6b5e88 / D0 0x6b5f5c: destroys the table — if +0x14 (count) is 0,

  0x732aac (base). +0x33 bit0 = skip the +0x20 sub-object teardown
